# Contributing

Thanks for taking the time to contribute. This guide keeps submissions consistent and useful.

## Inclusion criteria

Every project must meet all three criteria:

1. **Fully open source** — all code must be publicly available on a forge such as GitHub, GitLab, or Codeberg.
2. **Extensible** — users can add features, models, integrations, or otherwise customize behavior.
3. **Lightweight** — minimal bloat, fast startup, and a small resource footprint.

## How to add a project

1. Fork the repository.
2. Add the project to `data/awesome.json` with the required fields.
3. Add a one-line entry in the README under the appropriate category and the All Projects table.
4. Ensure the README and `data/awesome.json` stay in sync.
5. Open a pull request with a short justification.

## Description style guide

- Write in English.
- One line per entry, no more than ~120 characters.
- Start with a capital letter and end with a period.
- Be factual and specific; avoid marketing fluff.
- Do not add per-item emojis, badges, or caveats.

## Verification

All submissions must be fully open source. Closed-source, partially open-source, or source-available-only projects will not be accepted.
